# Support

For installation help, read [Troubleshooting](docs/TROUBLESHOOTING.md).

- Bugs: open a reproducible [GitHub issue](https://github.com/aliteleb/LanPilot/issues/new/choose).
- Feature requests: use the feature-request issue form.
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md) and report privately.

LanPilot is a community open-source project and does not currently provide a guaranteed support SLA.
